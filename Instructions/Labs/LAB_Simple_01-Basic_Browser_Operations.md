# Simple Lab 01 - Basic Browser Operations

## Lab introduction

In this lab, you will learn basic web browser operations including opening a browser, navigating to websites, and using search functions. These fundamental skills are essential for computer users.

## Estimated timing: 10 minutes

## Lab scenario

You need to access information on the internet using a web browser. In this exercise, you will perform basic browser operations to familiarize yourself with navigation and search functionality.

## Job skills

+ Task 1: Open a web browser and navigate to a website
+ Task 2: Perform a web search

## Task 1: Open a web browser and navigate to a website

In this task, you will open your default web browser and navigate to a specific website.

1. Click on the **Start menu** on the taskbar at the bottom of the screen.

2. Type `Microsoft Edge` (or your default browser name like Chrome, Firefox) and press **Enter**.

3. Wait for the browser to launch completely and display the home page.

4. In the address bar (the white field at the top showing the current URL), click to select it.

5. Type `https://www.microsoft.com` and press **Enter**.

6. Wait for the website to load and observe the content displayed on the screen.

7. **Note:** Record the main title or heading visible on the Microsoft homepage.

## Task 2: Perform a web search

In this task, you will use the search functionality of your browser to search for information.

1. Open a new browser tab by pressing **Ctrl + T** or clicking the **+ icon** at the top of the browser.

2. The cursor should be in the search/address bar. Type `what is cloud computing` and press **Enter**.

3. Observe the search results page that appears.

4. Click on one of the search results to view the article or page.

5. Read the first paragraph to understand what cloud computing means.

6. Navigate back to the search results by pressing **Alt + Left arrow** or clicking the **Back button**.

7. Take a screenshot of the search results page for your records.

## Summary

In this lab, you have successfully:
- Opened a web browser
- Navigated to a specific website (Microsoft.com)
- Performed a web search for information
- Navigated through search results

These basic browser skills form the foundation for accessing information and services online.
