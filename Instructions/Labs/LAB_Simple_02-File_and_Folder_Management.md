# Simple Lab 02 - File and Folder Management

## Lab introduction

In this lab, you will learn how to create, rename, and organize files and folders on your computer. Proper file management is essential for keeping your data organized and easy to find.

## Estimated timing: 15 minutes

## Lab scenario

You need to organize your work files by creating a folder structure and managing documents. In this exercise, you will create folders, move files, and rename items to practice file management skills.

## Job skills

+ Task 1: Create folders in the Documents directory
+ Task 2: Rename and organize files

## Task 1: Create folders in the Documents directory

In this task, you will create a new folder structure to organize your files.

1. Click on the **File Manager icon** in the taskbar, or press **Windows key + E**.

2. Navigate to the **Documents** folder by clicking on it in the left sidebar.

3. Right-click in the empty space within the Documents folder.

4. Select **New** from the context menu, then select **Folder**.

5. Type `MyLab_Documents` as the folder name and press **Enter**.

6. Double-click the newly created folder to open it.

7. Right-click in the empty space and create two more folders:
   - Name the first folder `Projects`
   - Name the second folder `Resources`

8. Close the File Manager window.

## Task 2: Rename and organize files

In this task, you will work with files to practice renaming and organization.

1. Open File Manager again and navigate to **Documents > MyLab_Documents > Projects**.

2. Right-click in the empty space and select **New > Text Document**.

3. A new file will appear. Type a new name: `ProjectPlan.txt` and press **Enter**.

4. Create two more text files:
   - `Tasks.txt`
   - `Notes.txt`

5. Right-click on **ProjectPlan.txt** and select **Rename**.

6. Change the name to `ProjectPlan_v2.txt` and press **Enter**.

7. Navigate to the **Resources** folder and paste copies of these files by:
   - Selecting all files (Ctrl + A)
   - Copy them (Ctrl + C)
   - Navigate to Resources folder
   - Paste (Ctrl + V)

8. Verify that the files are now in both the Projects and Resources folders.

## Summary

In this lab, you have successfully:
- Created a folder structure using File Manager
- Created new text files
- Renamed files
- Copied and pasted files between folders

These file management skills are fundamental for organizing your digital workspace efficiently.
