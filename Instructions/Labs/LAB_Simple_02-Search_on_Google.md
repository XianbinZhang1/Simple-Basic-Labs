# Simple Lab 02 - Search on a Website

## Lab introduction

In this lab, you will learn how to use a website search box to find information. Knowing how to search effectively is essential for finding information online.

## Estimated timing: 5 minutes

## Important for Testing

If a browser permission popup appears (for example, Location or Notifications), click **Block** or **Not now** so the popup does not interrupt the lab flow.

## Lab scenario

You need to find information about a topic on the internet. You will use a website search function to find this information step by step.

## Job skills

+ Task 1: Navigate to a search page
+ Task 2: Perform a basic search
+ Task 3: View search results

## Task 1: Navigate to a Search Page

In this task, you will open a website with a search function.

1. Click on the address bar at the top of your browser.

2. Type `https://www.example.com` and press **Enter**.

3. Wait for the page to load completely.

4. You will see a simple example website.

## Task 2: Perform a search using a search box

In this task, you will search for information.

1. Look for any **search box** or **input field** on the page.

2. Alternatively, navigate to `https://www.wikipedia.org` which has a search box.

3. Click on the **search box** at the top of the page.

4. Type `computer` as your search query.

5. Press **Enter** or click the **Search button**.

6. Wait for the search results page to load.

## Task 3: View search results

In this task, you will examine the search results.

1. Observe the list of search results displayed on the page.

2. Each result shows:
   - The article title (usually in a link format)
   - A brief description or summary

3. Click on the **first search result** to visit that page.

4. Read the content of the article.

5. Go back to the search results by clicking the **Back button** in your browser (usually a left arrow at the top left).

## Summary

In this lab, you have successfully:
- Navigated to a search page
- Entered a search query
- Viewed search results
- Clicked on a search result to visit a website
- Used the browser's back button to return to search results

These search skills will help you find information about any topic on the internet.
