# Simple Lab 03 - Text Editor Operations

## Lab introduction

In this lab, you will learn how to use a text editor to create, edit, and save documents. Text editors are fundamental tools for writing notes, code, and documents on your computer.

## Estimated timing: 12 minutes

## Lab scenario

You need to create and edit text documents for various purposes. In this exercise, you will open a text editor, write content, format it, and save it with a proper filename.

## Job skills

+ Task 1: Open a text editor and create a document
+ Task 2: Edit and save the document

## Task 1: Open a text editor and create a document

In this task, you will open the Notepad text editor and create a new document.

1. Click on the **Start menu** on the taskbar.

2. Type `Notepad` in the search box and press **Enter** to open Notepad.

3. The blank Notepad window will open. You can now type your content.

4. Type the following text:
   ```
   My First Lab Document
   
   Date: Today's Date
   
   In this lab, I am learning about basic computer operations.
   
   Tasks completed:
   - Opened a text editor
   - Created a new document
   - Added content to the document
   ```

5. Observe that the title bar shows **Untitled - Notepad** indicating the file has not been saved yet.

## Task 2: Edit and save the document

In this task, you will make edits to your document and save it.

1. Click at the end of the last line in your document.

2. Press **Enter** twice to add blank lines.

3. Type the following:
   ```
   Additional Notes:
   - Remember to save your work regularly
   - Use meaningful filenames for your documents
   ```

4. Now save the document by pressing **Ctrl + S**.

5. In the **Save As** dialog that appears:
   - Navigate to **Documents > MyLab_Documents > Projects** (from the previous lab)
   - In the **File name** field, type: `Lab_Notes.txt`
   - Verify the **Save as type** is set to **Text Documents (*.txt)**
   - Click the **Save** button

6. Observe that the title bar now shows **Lab_Notes.txt - Notepad** confirming the file is saved.

7. Make one more edit: Press **Ctrl + End** to go to the end of the document and add:
   ```
   
   Last updated: Today's Date and Time
   ```

8. Save the changes by pressing **Ctrl + S**.

9. Close Notepad by clicking the **X** button or pressing **Alt + F4**.

## Summary

In this lab, you have successfully:
- Opened the Notepad text editor
- Created a new text document with content
- Edited the document by adding more text
- Saved the document with a meaningful filename
- Saved changes to an existing file

These text editing skills are essential for creating and maintaining text-based documents and notes.
