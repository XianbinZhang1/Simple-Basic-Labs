# Simple Lab 04 - System Information and Settings

## Lab introduction

In this lab, you will learn how to access and view important system information about your computer, including the operating system version, installed hardware, and system settings. Understanding where to find this information is crucial for troubleshooting and system management.

## Estimated timing: 15 minutes

## Lab scenario

You need to verify your computer's specifications and system information, such as the operating system version, processor type, and installed memory. In this exercise, you will navigate through various system settings to gather this information.

## Job skills

+ Task 1: View system information
+ Task 2: Access system settings and display preferences

## Task 1: View system information

In this task, you will access your computer's detailed system information.

1. Right-click on the **This PC** icon on the desktop or in the File Manager sidebar.

2. Select **Properties** from the context menu.

3. The **System** settings window will open. Record the following information:
   - **Device name:** (the computer's name)
   - **Processor:** (CPU information)
   - **Installed RAM:** (memory amount)
   - **System type:** (32-bit or 64-bit)

4. Note the **Windows edition** and **OS build** information displayed.

5. Scroll down to see additional system information if available.

6. Alternatively, press **Windows key + Pause/Break** to quickly access this system properties window.

7. You can also access detailed System Information by:
   - Right-clicking the **Start menu**
   - Selecting **System** or **Settings > System > About**

## Task 2: Access system settings and display preferences

In this task, you will navigate through system settings and customize display preferences.

1. Click the **Start menu** and select **Settings** (or press **Windows key + I**).

2. In the Settings window, explore the following sections:
   - Click on **System** to see system-related settings
   - Click on **About** to view OS and build information
   - Note the **Windows specs** section showing your OS version

3. Now modify a display setting:
   - From the Settings window, select **System** (if not already selected)
   - Click on **Display** in the left sidebar
   - Observe the current screen **Resolution** setting
   - Note the **Brightness and color** options

4. You can change the screen brightness by adjusting the brightness slider, but do not save changes unless directed.

5. Click on **Advanced display settings** to see more detailed display information:
   - Refresh rate
   - Color depth
   - Monitor resolution options

6. Return to the main Settings window and explore **Devices** to see:
   - Connected peripherals (keyboard, mouse, etc.)
   - Installed printers

7. Close the Settings window.

## Summary

In this lab, you have successfully:
- Accessed system properties to view computer specifications
- Located and recorded system information (processor, RAM, OS version)
- Navigated through Windows Settings
- Explored display and device preferences
- Understood where to find critical system information for troubleshooting

This knowledge is essential for system administrators and users who need to verify hardware specifications or troubleshoot system-related issues.
