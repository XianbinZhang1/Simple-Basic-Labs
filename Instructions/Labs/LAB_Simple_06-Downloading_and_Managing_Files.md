# Simple Lab 06 - Downloading and Managing Downloaded Files

## Lab introduction

In this lab, you will learn how to download files from the internet and manage them properly. Understanding how to download and organize files is essential for working with online resources and software.

## Estimated timing: 15 minutes

## Lab scenario

You need to download a file from the internet and organize it in your file system. In this exercise, you will download a file, locate it in your Downloads folder, and move it to an appropriate location.

## Job skills

+ Task 1: Download a file from the internet
+ Task 2: Manage and organize downloaded files

## Task 1: Download a file from the internet

In this task, you will download a file using your web browser.

1. Open your web browser (Microsoft Edge, Chrome, or Firefox).

2. Navigate to a website that offers free downloadable content. For this lab, use one of these:
   - `https://www.w3.org/` (search for downloadable documents)
   - or any website that provides documents for download

3. Search for a simple downloadable file (PDF, document, or text file).

4. Locate a download link for a file you want to download.

5. When you find a file to download, click the download link.

6. Depending on your browser:
   - A dialog box may appear asking where to save the file
   - Or the file will automatically save to your **Downloads** folder
   - If prompted, click **Save** to confirm the download

7. Wait for the download to complete. You should see a completion message or notification.

8. Note the filename and file type (e.g., index.html, document.pdf).

## Task 2: Manage and organize downloaded files

In this task, you will locate, organize, and manage the downloaded file.

1. Open **File Manager** and navigate to the **Downloads** folder.

2. You should see the file you just downloaded.

3. **Alternative method to access Downloads:**
   - Click the **Downloads folder** in the left sidebar
   - Or navigate manually through Documents > Downloads

4. Right-click on the downloaded file and view its **Properties**:
   - File size
   - File type
   - Date downloaded
   - Full file path

5. To organize the file, you have several options:

   **Option A: Create a Downloads backup folder**
   - Go to **Documents > MyLab_Documents**
   - Create a new folder called `DownloadedFiles`
   - Move the downloaded file to this new folder

6. To move the file:
   - Right-click on the downloaded file in the Downloads folder
   - Select **Cut**
   - Navigate to **Documents > MyLab_Documents > DownloadedFiles**
   - Right-click and select **Paste**

7. Verify the file is now in your organized location.

8. **To verify the move was successful:**
   - Return to the Downloads folder
   - Confirm the file is no longer there
   - Navigate to Documents > MyLab_Documents > DownloadedFiles
   - Confirm the file is present

9. If you want to keep a copy in Downloads, use **Copy** instead of **Cut**.

10. Right-click on the file in its new location and verify you can open it.

## Summary

In this lab, you have successfully:
- Downloaded a file from the internet using a web browser
- Located the file in the Downloads folder
- Accessed the file's properties and metadata
- Moved or copied the downloaded file to an organized location
- Verified the successful transfer of the file

These download management skills are essential for working with online resources and maintaining an organized file system.
