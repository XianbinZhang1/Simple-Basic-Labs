# Simple Lab 08 - Refresh and Reload Pages

## Lab introduction

In this lab, you will learn how to refresh and reload web pages. Refreshing is useful when a page hasn't loaded correctly or when you want to see the latest content on a website.

## Estimated timing: 5 minutes

## Lab scenario

A website is showing outdated information or hasn't loaded properly. You need to refresh the page to get the latest content or fix loading issues.

## Job skills

+ Task 1: Understand page refresh
+ Task 2: Perform a normal refresh
+ Task 3: Perform a hard refresh
+ Task 4: Stop page loading

## Task 1: Understand page refresh

In this task, you will learn what refresh does.

1. When you **refresh a page**, the browser:
   - Downloads the page again from the server
   - Gets the latest content
   - Updates any information that changed

2. This is useful when:
   - A page didn't load completely
   - Information seems outdated
   - A page has an error
   - You want to see live updates

## Task 2: Perform a normal refresh

In this task, you will use the normal refresh function.

1. Navigate to `https://www.news.bbc.co.uk/` or any news website.

2. Wait for the page to load completely.

3. Look for the **refresh icon** (circular arrow) in the address bar area at the top left of your browser.

4. Click the **refresh button**.

5. The page will reload, and you might see updated news stories or information.

6. Wait for the page to load again.

**Keyboard shortcut for normal refresh:**
- Press **F5** on your keyboard
- Or press **Ctrl + R**

## Task 3: Perform a hard refresh

In this task, you will learn about hard refresh (clearing the cache).

1. A **hard refresh** completely clears the browser's temporarily saved data (cache) for that page.

2. This is useful when:
   - A page is showing very old content
   - Updates aren't appearing even after normal refresh
   - You want a completely fresh version

3. To perform a **hard refresh**, hold **Ctrl** and press **F5**.

**Alternative method:**
- Press **Ctrl + Shift + R** (in some browsers)

4. The page will reload completely without using any cached data.

5. You may notice it takes slightly longer to load as everything is downloaded fresh.

## Task 4: Stop page loading

In this task, you will learn to stop a page that's taking too long to load.

1. Navigate to any website.

2. While the page is still loading (you'll see the page partially loaded and the refresh button shows a loading animation):

3. Look for the **stop button** (X icon) in the address bar.

4. Click the **stop button** to stop the page download.

**Keyboard shortcut:**
- Press **Escape** key to stop loading

5. The page will stop loading at that point, and you can still view the partially loaded content.

6. You can then click the refresh button to try loading again if needed.

## Optional: Clearing Browser Cache

1. Press **Ctrl + Shift + Delete** to open the cache-clearing dialog.

2. You can select:
   - Time range (Last hour, Last day, All time)
   - What to clear (Browsing history, Cookies, Cached images/files)

3. This clears temporary storage completely (more drastic than a hard refresh).

## Summary

In this lab, you have successfully:
- Understood what page refresh does
- Performed a normal refresh to reload a page
- Performed a hard refresh to clear cache
- Stopped a page that was loading too slowly
- Learned when to use different refresh methods

These page management skills help you troubleshoot loading issues and ensure you're viewing the most current web content.
