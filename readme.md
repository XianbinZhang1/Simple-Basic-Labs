# Simple Basic Labs

This repository contains 8 very simple, beginner-friendly labs that do not depend on Azure Portal.

## Labs Included

1. Basic Browser Operations
2. File and Folder Management
3. Text Editor Operations
4. System Information and Settings
5. File Compression and Archiving
6. Downloading and Managing Files
7. Task Manager and Process Monitoring
8. Control Panel and System Services

## Lab Location

All lab files are under:

- Instructions/Labs/

## Target Audience

These labs are designed for beginners who want to practice basic Windows and browser operations with step-by-step instructions.
